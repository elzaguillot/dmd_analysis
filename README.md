# dmd_analysis

Analysis code for Guillot et al., *dynamic gene regulatory network in Duchenne muscular dystrophy initiation*.

The repository starts from count and intensity tables. Read alignment is documented below with the
commands that were run, but is not part of the scripts. The gene regulatory network inference is not
covered here.

| Analysis | Script | Paper |
|---|---|---|
| Bulk RNA half-life (actinomycin D) | `scripts/half_life.py` | Results, bulk RNA-seq |
| TMT proteomics | `scripts/proteomics.py` | Fig S26 |
| scRNAseq1 (10x) preprocessing | `scripts/preprocessing_scrnaseq1.py` | Methods |
| scRNA-seq trajectory and siRNA validation | to come | Fig 1, 3, S1–S20, S27 |

## Installation

Python ≥ 3.12, dependencies declared in `pyproject.toml`:

```bash
uv sync
```

Every script then runs with `uv run python scripts/<script>.py`; `--help` lists its options.

## Data

Datasets are deposited on ArrayExpress (E-MTAB-16077, E-MTAB-16083). Scripts read their inputs from
`data/` and write to `results/`. The inputs below and the final tables (`results/*/*.csv`,
`results/scrnaseq1/scrnaseq1_preprocessed.h5ad`) are versioned; figures are regenerated by the scripts.

```
data/
├── half_life/kallisto/{D5,D7,D9}_T{0..4}/abundance.tsv   kallisto output per sample
├── reference/Homo_sapiens.GRCh38.cdna.all.fa.gz           Ensembl cDNA FASTA, for gene symbols (downloaded)
├── proteomics/Proteomic_result.csv                        EDyP protein group export
└── scrnaseq/1-all_Velocyto.h5ad                           10x pools after CellRanger, HTO and velocyto
```

## Bulk RNA half-life

UC3-4 cells, actinomycin D (10 µg/mL) at day 5, 7 and 9 of differentiation, collected 0 to 4 h after
treatment (15 samples).

Upstream, per sample (fastp, then kallisto 0.46.0 on an index of the Ensembl release 100 GRCh38
cDNA, 190,522 transcripts):

```bash
fastp -i R1.fastq.gz -I R2.fastq.gz -o R1.fastq -O R2.fastq --detect_adapter_for_pe -q 30 -c
kallisto quant -i Homo_sapiens.GRCh38.cdna.index.idx -o kallisto/D5_T0 -b 100 R1.fastq R2.fastq
```

```bash
sh scripts/download_reference.sh
uv run python scripts/half_life.py
```

1. Sums transcript TPM per gene with the transcript-to-gene table of the kallisto index (as
   `tximport(type = "kallisto")`).
2. For each gene and day, fits `y = a·exp(−d0·t)` on the expression normalised by its maximum.
   The fit is skipped with fewer than 3 non-zero time points; d0 < 0.01 h⁻¹ is reported as missing.
3. Flags fits with r² > 0.6.

Outputs in `results/half_life/`:
- `tpm_per_gene.csv`: gene × sample TPM;
- `d0_per_gene.csv`: per day, d0 (h⁻¹), amplitude a (TPM), r², half-life (h) and the r² flag;
- `figures/`: distributions, decay fits and pre-treatment expression for ENO1, MIF, PRTG, ID1, PDGFRA, PTN.

## Proteomics

WT and DMD mutant cells, days 5, 6, 7, 8, 9, 10, 12 and 14, 3 replicates, TMTpro 16plex, nano-LC-MS/MS
at the EDyP platform (5,635 protein groups).

```bash
uv run python scripts/proteomics.py
```

1. Swaps the WT and Mut day 14 columns, which are inverted in the export.
2. Assigns an Ensembl gene to each protein group. Protein groups with several Ensembl ids and several
   gene names are removed, the remaining ambiguous ones were resolved by hand. Protein groups of the
   same gene are summed (5,373 genes).
3. Converts intensities to copies per cell with the histone proteomic ruler
   (Wiśniewski et al. 2014, *Mol Cell Proteomics* 13:3497): `N_A · I / (MW · ΣI_histones)`, with the
   histone mass per cell set to 1, so values are proportional to copies per cell.
4. Averages replicates per genotype and day when at least 2 are quantified.

Outputs in `results/proteomics/`:
- `protein_copies_per_cell.csv`: one row per gene, genotype, day and replicate;
- `protein_mean.csv`: replicate mean and number of quantified replicates;
- `figures/protein_genes_of_interest.png`: ENO1, ID1, MIF, PRTG (PDGFRA and PTN are not detected).

## scRNAseq1 preprocessing

UC3-4 (healthy) and DMD cells, days 5 to 14, two 10x pools labelled with hashtags (HTO): pool 1 days 5–8,
pool 2 days 9–14 (14 conditions, 10,965 cells).

Upstream, per pool (CellRanger 7.1.0, `refdata-gex-GRCh38-2020-A`, then velocyto):
1. CellRanger `count`; cells kept above log10 UMI 3.9 and 3,800 genes (pool 1) or log10 UMI 3.4 and
   1,500 genes (pool 2), then CellRanger rerun with `--force-cells` set to that number.
2. Condition assigned from the HTO counts: a cell gets the condition of the HTO holding more than 70 %
   (pool 1) or 30 % (pool 2) of its HTO counts; other cells are removed.
3. velocyto spliced/unspliced counts merged with CellRanger counts (`scvelo.utils.merge`), both pools
   concatenated into `1-all_Velocyto.h5ad`.

```bash
uv run python scripts/preprocessing_scrnaseq1.py
```

1. Computes QC metrics on the CellRanger counts (UMI, detected genes, % mitochondrial `MT-` and ribosomal
   counts); no cell is filtered.
2. Removes ribosomal genes (name starting with `RPS`, `RPL`, `MRPS`, `MRPL`, 184 genes) and MALAT1.
3. Keeps genes detected spliced and unspliced in the same cell at least once
   (`scv.pp.filter_and_normalize(min_shared_counts=1)`, 17,118 genes) and normalises spliced counts to the
   median spliced count per cell, without log.

As in the original analysis, the ribosomal prefix also removes some non-ribosomal genes (RPS6K* kinases,
RPS19BP1, antisense transcripts). The output is identical to the original `3-all_Velocyto.h5ad`, except
`pct_counts_mt`, which was 100 % for every cell in the original (all genes were flagged mitochondrial
after the two pools were concatenated).

Outputs in `results/scrnaseq1/`:
- `scrnaseq1_preprocessed.h5ad`: `X` and `layers["spliced"]` normalised spliced counts,
  `layers["raw_spliced"]` spliced counts, `unspliced`, `ambiguous`, `matrix` (CellRanger counts);
- `cells_per_condition.csv`;
- `figures/`: per pool knee plot, UMI, genes, mitochondrial and ribosomal distributions; QC per condition.
